    5 · Ejemplos resueltos

    para explicar en clase
    Ejemplo 1 — Suma

    A = (4, 3)  ·  B = (−2, 5)

    • 1. Se suman componente a componente
    • 2. Rₓ = 4 + (−2) = 2
    • 3. Rᵧ = 3 + 5 = 8
    • 4. |R| = √(2² + 8²) = √68 ≈ 8.25
    R = (2, 8)
    Ejemplo 2 — Resta

    A = (6, 2)  ·  B = (1, 4)

    • 1. A − B = A + (−B)
    • 2. Rₓ = 6 − 1 = 5
    • 3. Rᵧ = 2 − 4 = −2
    • 4. |R| = √(25 + 4) = √29 ≈ 5.39
    R = (5, −2)
    Ejemplo 3 — Magnitud y dirección

    A = (3, 4)

    • 1. |A| = √(a₁² + a₂²)
    • 2. |A| = √(3² + 4²) = √25
    • 3. θ = arctan(4 / 3)
    • 4. θ ≈ 53.13°
    |A| = 5 ; θ ≈ 53.13°
    Ejemplo 4 — Producto punto

    A = (2, 3)  ·  B = (4, −1)

    • 1. A · B = a₁b₁ + a₂b₂
    • 2. = (2)(4) + (3)(−1)
    • 3. = 8 − 3
    A · B = 5
    Ejemplo 5 — Ángulo entre vectores

    A = (1, 0)  ·  B = (1, 1)

    • 1. cos θ = (A·B) / (|A||B|)
    • 2. A·B = 1 ; |A| = 1 ; |B| = √2
    • 3. cos θ = 1/√2 = 0.7071
    θ = 45°
    Ejemplo 6 — Escalar

    k = 2  ·  A = (3, 1)

    • 1. k·A = (k·a₁, k·a₂)
    • 2. = (2·3, 2·1)
    • 3. El vector conserva su dirección
    • 4. Su magnitud se duplica
    2A = (6, 2)

    6 · Fundamento teórico

    fórmulas del tema

    ¿Qué es un vector?

    Es un segmento orientado que posee magnitud (tamaño), dirección (ángulo) y sentido. Se representa por sus componentes rectangulares.

    A = (a₁, a₂) = a₁î + a₂ĵ

    Magnitud o módulo

    Se obtiene con el teorema de Pitágoras aplicado a las componentes.

    |A| = √(a₁² + a₂²)

    Dirección

    Ángulo medido desde el eje x positivo, en sentido antihorario.

    θ = arctan(a₂ / a₁)

    Suma y resta

    Se operan las componentes correspondientes. Gráficamente se usa el método del paralelogramo o del triángulo.

    A ± B = (a₁ ± b₁, a₂ ± b₂)

    Producto por un escalar

    Cambia la magnitud. Si k < 0 además invierte el sentido del vector.

    k·A = (k·a₁, k·a₂)

    Producto punto

    Da como resultado un número real. Si es cero, los vectores son perpendiculares.

    A·B = a₁b₁ + a₂b₂ = |A||B|cos θ

    Ángulo entre vectores

    Se despeja del producto punto.

    θ = arccos( (A·B) / (|A|·|B|) )

    Vector unitario

    Vector de magnitud 1 con la misma dirección que A.

    û = A / |A|

    Producto cruz en el plano

    Su valor absoluto es el área del paralelogramo formado por A y B.

    A × B = a₁b₂ − a₂b₁

    Proyección

    Sombra de A sobre la dirección de B.

    proy_B A = [(A·B)/|B|²] · B
